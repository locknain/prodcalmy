Install ProdCalMY as an App

Add ProdCalMY to your home screen or desktop dock to launch it full-screen with offline access:

iPhone / iPad (Safari)

Tap the Share icon in Safari's toolbar, scroll down, and choose Add to Home Screen.

Android (Chrome / Edge)

Tap the browser ⋮ Menu in the top corner and select Install app or Add to Home screen.

Desktop (Chrome / Edge / Brave)

Click the Install icon inside the browser address bar or open browser menu → Install ProdCalMY.
